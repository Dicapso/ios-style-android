# iOS-style Launcher & Dialer for Android

![Kotlin](https://img.shields.io/badge/Kotlin-3b3a36?style=flat-square) ![Jetpack Compose](https://img.shields.io/badge/Jetpack%20Compose-3b3a36?style=flat-square) ![InCallService](https://img.shields.io/badge/InCallService-3b3a36?style=flat-square) ![Android SDK](https://img.shields.io/badge/Android%20SDK-3b3a36?style=flat-square)


Two system-level Android apps with an iPhone look.

## Dialer
- A **full default dialer**: keypad, incoming/outgoing calls, live in-call screen (answer / end)
- Built on `InCallService`; a `StateFlow` bridge keeps the service and Compose UI in sync
- Handles default-dialer role and runtime permissions on first launch

## Launcher
- Home screen with dock, app pages and an app library
- Compose UI tuned to feel like iOS spacing, icons and motion
